# Décisions techniques (ADR)

Une décision structurante = un fichier `NNNN-titre-court.md`, copié depuis `0000-template.md`.
Un ADR n'est jamais modifié après acceptation : si la décision change, on en écrit un nouveau
qui « remplace » l'ancien, et on passe l'ancien au statut « Remplacé par NNNN ».

Pourquoi : l'agent (et toi dans 6 mois) sait pourquoi les choses sont ainsi, et ne remet pas
une décision en cause sans raison nouvelle.
