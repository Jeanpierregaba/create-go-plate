# Specs

Un dossier par fonctionnalité : `NNN-nom-court/` (ex : `001-authentification/`), créé par `/spec`
à partir de `_template/`.

| Fichier | Contenu | Validé par l'utilisateur avant… |
|---|---|---|
| `spec.md` | Le QUOI : comportement attendu, critères d'acceptation | le plan |
| `plan.md` | Le COMMENT : fichiers, données, API, dépendances | le découpage |
| `tasks.md` | Les tâches ordonnées, cochées au fil de l'eau | le code |

Une spec terminée reste dans le dépôt : elle documente pourquoi le code est comme il est.
